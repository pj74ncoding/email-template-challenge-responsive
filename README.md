## Installation

### Clone the Repository

```bash
git clone https://github.com/pj74ncoding/email-template-challenge-responsive.git
cd email-template-challenge-responsive



```

### Install Dependencies

Frontend:

```bash
cd email-template-challenge-responsive



npm install
```

### Run Development Servers

Frontend:

```bash
npm start
```
